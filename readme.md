# 3D Architectural Studio

منصة تفاعلية ثلاثية الأبعاد لعرض التصاميم المعمارية، التجول الداخلي، وإنتاج مقاطع فيديو سينمائية بصيغة MP4/WebM مباشرة من المتصفح باستخدام Three.js و Vite.

---

## 💡 المميزات الأساسية

* **استيراد النماذج**: إمكانية رفع واستعراض ملفات `GLTF` / `GLB` المخصصة أو تحميل نموذج مبنى افتراضي جاهز.
* **أنماط الكاميرا والتجول**:
  * **Orbit Mode**: نمط الدوران حول المبنى للاستكشاف والتصميم.
  * **First Person (FPS)**: تجول تفاعلي بمستوى رؤية الإنسان مع نظام تصادم (Collision Detection) ودعم الذراع الافتراضية (Joystick) للأجهزة الذكية.
  * **إسقاطات هندسية**: مشاهدة سريعة من الأعلى (Top View) ومن الأمام (Front View).
* **إضاءة متغيرة**: تبديل مباشر بين أوضاع الإضاءة (نهار، غروب، ليل).
* **أداة القياس**: قياس المسافات المباشرة بين أي نقطتين في المشهد.
* **أنماط مسارات سينمائية (Keyframe Timeline)**:
  * تسجيل حركات الكاميرا عبر شريط زمني لتحديد اللقطات (Keyframes).
  * أنماط حركة جاهزة مثل الكشف المعماري والدوران الخارجي.
* **تصدير الفيديو**: تسجيل الشاشة مباشرة وتصدير العرض السينمائي بدقة تصل إلى 1080p وتردد 60 FPS.
